# 双均线交叉策略

## 策略简介

双均线交叉策略是一种简单的趋势跟踪策略。它使用两条不同周期的移动平均线，比较短期趋势和较长期趋势的相对强弱，并把均线交叉转换为交易信号。

本策略使用：

- **MA5**：最近 5 个交易日收盘价的平均，反应较敏感；
- **MA20**：最近 20 个交易日收盘价的平均，更平滑但反应较慢。

## 核心逻辑

- **金叉**：MA5 从下向上穿过 MA20，表示短期趋势相对变强，作为买入参考；
- **死叉**：MA5 从上向下穿过 MA20，表示短期趋势相对变弱，作为卖出参考。

需要注意，金叉和死叉首先是均线之间的交叉现象。只有把它们明确写成买入、卖出和持仓规则后，才构成一个可以回测的交易策略。

## 交易规则

最简单的规则是：

```text
如果 MA5 > MA20：持有
否则：空仓
```

也可以用交叉当天产生交易信号：

```text
金叉：买入
死叉：卖出
```

在 pandas 中计算均线和持仓信号：

```python
df["MA5"] = df["Close"].rolling(5).mean()
df["MA20"] = df["Close"].rolling(20).mean()
df["signal"] = (df["MA5"] > df["MA20"]).astype(int)
```

其中 `signal = 1` 表示持仓，`signal = 0` 表示空仓。

## 策略流程

1. 获取股票的历史日线数据；
2. 使用收盘价计算 MA5 和 MA20；
3. 比较两条均线，生成持仓信号；
4. 用下一交易日的价格执行信号，避免使用未来数据；
5. 计算策略收益，并与买入并持有策略比较；
6. 检查交易次数、手续费、滑点、最大回撤和波动率。

## 策略的优点

- 规则简单，容易理解和编程；
- 能够过滤一部分短期价格噪声；
- 在持续上涨或持续下跌的趋势行情中，可能捕捉到较大的趋势段。

## 策略的局限

- 移动平均线具有滞后性，趋势反转后信号不会立即出现；
- 震荡行情中，MA5 和 MA20 可能频繁交叉，产生连续买卖和交易成本；
- 金叉不代表一定上涨，死叉也不代表一定下跌；
- MA5、MA20 只是参数选择，需要通过历史回测检验，不能直接认为有效；
- 回测结果还需要考虑手续费、滑点、停牌、涨跌停和实际成交限制。

## 回测时要回答的问题

- 策略在不同时间段是否都有效？
- 策略收益是否超过买入并持有？
- 最大回撤是多少？
- 盈利是否只来自少数几次交易？
- 更换股票、时间窗口或均线参数后，结果是否仍然稳定？

双均线交叉策略是学习“把观察到的现象写成规则，再用历史数据验证”的入门例子，不是保证盈利的交易公式。
