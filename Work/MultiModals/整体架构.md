Resource Instance Graph ^TpLfLVQp

每个 Resource Instance 描述一个有形的（比如罐装线上的 UR5 机器人）
或者一个无形的（比如 HC 车间中的 Line C） 对象。包括这个对象有哪些
可被观察的数据、文件、其他静态资产以及这个对象上具备哪些能力。
可被观察的数据、文件、其他静态资产的配置我们称为 property，
具备的能力的配置我们称为 behavior。
Resource Instance 是人/AI 操作的基本单元。

Graph 中的 Edge 表示多个 Resource Instance 之间的关系。
人/AI 通过 Resource Instance Graph 来了解全貌，
拥有哪些东西，这个东西之间的关系是什么样子的。
深入到单个 Resource Instance 中，来了解这个东西有哪些数据，具备哪些能力 ^NmY586b1
