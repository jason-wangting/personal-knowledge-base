## 第 5 页：我的个人 AI Coding 简化流程
提示词：
生成一页“个人 AI Coding 实践流程”页面，用横向流程图展示 4 个大步骤：需求分析 -> 制定 Plan -> 实现 -> Review。每个大步骤下方补充 AI 可以协助的事情。需求分析阶段包含：与 AI 讨论需求合理性、补全边界和完善需求。制定 Plan 阶段包含：让 AI 根据需求拆分任务生成 Plan，人来 Review Plan，也可以让 AI 自己检查 Plan 中的问题。实现阶段包含：按 Plan 的不同 task 实现、必要时启动多 agent 并行、必要时引入 TDD。Review 阶段包含：启动独立的 Review Agent，基于 git diff 做代码审查。风格专业、简洁、工程化、结构清晰。

备注：
这一页我想先把我的个人实践流程讲清楚，而且只保留最核心的 4 个步骤。第一步是需求分析，我会先和 AI 把需求的合理性、边界和遗漏讨论清楚。第二步是制定 Plan，让 AI 先把需求拆成可执行的任务，我来 Review，也会让 AI 再检查一次 Plan 本身。第三步才进入实现，必要时按 task 启动多 agent 协作，或者在高风险场景下加上 TDD。最后一步是 Review，我会启动独立的 Review Agent，基于 git diff 去看这次改动有没有问题。

重点描述：
- 需求分析：和 AI 讨论合理性，补边界，完善需求
- 制定 Plan：AI 拆分任务生成人类可审的 Plan，必要时让 AI 自检 Plan
- 实现：按 task 推进，必要时使用多 agent 和 TDD
- Review：启动独立 Review Agent，基于 git diff 审查代码
